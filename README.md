# 내 비서 · 설치와 업데이트

처음 한 번만 설치하면 그 뒤 업데이트는 앱이 알아서 받아요.

1. 휴대폰(안드로이드 13 이상)에서 아래 링크를 눌러 설치 파일을 받으세요.
   **[내 비서 0.4.0 설치 파일 받기](https://github.com/hellotwizi-pixel/personal-assistant-updates/releases/download/v0.4.0/personal-assistant-0.4.0.apk)**
2. 받은 파일을 열고 설치하세요. "출처를 알 수 없는 앱" 허용 화면이 뜨면 이번 한 번만 허용해 주세요.
3. 끝이에요. 화면 업데이트는 앱을 열 때 자동으로 적용되고, 휴대폰 기능이 바뀌는 업데이트는 앱 설정의 **업데이트** 버튼으로 받아요.

기록은 각자 휴대폰 안에만 저장돼요. 이 저장소에는 앱 프로그램만 있고, 누구의 기록도 올라오지 않아요.
업데이트 파일은 서명되어 있어 다른 사람이 만든 가짜 업데이트는 앱이 거부해요.
