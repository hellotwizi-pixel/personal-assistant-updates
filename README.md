# 내 비서 · 설치 안내

처음 한 번만 설치하면, 그 뒤 업데이트는 앱이 알아서 받아요. 다시 설치할 일은 없어요.

## 1. 설치하기 (안드로이드 13 이상)
1. 휴대폰·태블릿에서 아래 링크를 눌러 설치 파일을 받으세요.
   **[내 비서 0.4.0 설치 파일 받기](https://github.com/hellotwizi-pixel/personal-assistant-updates/releases/download/v0.4.0/personal-assistant-0.4.0.apk)**
2. 받은 파일을 열고 **설치**를 누르세요.
   "출처를 알 수 없는 앱" 화면이 뜨면 → 그 화면의 **설정** → **이 출처 허용**을 켜고 뒤로 돌아와 설치하세요.

## 2. 꼭 켜야 하는 3가지 (앱 안에서 한 번만)
앱을 열고 오른쪽 위 **톱니바퀴(설정)** → **빠른 입력과 알림**에서 아래 세 줄의 **설정** 버튼을 하나씩 눌러 켜 주세요.

| 항목 | 왜 필요한가요 | 켜는 법 |
|---|---|---|
| **마이크 권한** | 말로 기록하려면 필요해요 | 설정 → **허용** (또는 "앱 사용 중에만 허용") |
| **알림 표시** | 약속 알림·보고를 받으려면 필요해요 | 설정 → **알림 허용** 켜기 |
| **정확한 시각의 알림** | 약속 10분 전처럼 정해진 시각에 정확히 울리려면 필요해요 | 설정 → **알람 및 리마인더 허용** 켜기 |

세 줄 모두 "허용됨"으로 바뀌면 끝이에요.

## 3. 측면 버튼으로 바로 기록하기 (추천)
버튼 두 번으로, 앱 화면을 거치지 않고 곧바로 말을 받아 적는 기능이에요.

1. 기기 **설정** → **유용한 기능** → **측면 버튼**
2. **두 번 누르기**를 켜고 → **앱 열기** → **내 비서**를 고르세요.
   목록에는 "내 비서"만 보여요. 그게 맞아요. 측면 버튼으로 열면 앱이 알아서 바로 듣기를 시작하고, 앱 아이콘을 눌러 열면 평소처럼 첫 화면이 열려요.
3. 이제 측면 버튼을 두 번 누르고 말하면 끝이에요. 말이 끝나면 저절로 저장돼요.

- 잠금 화면에서는 잠금을 먼저 풀어야 할 수 있어요(보안 잠금은 건드리지 않아요).
- 측면 버튼이 없거나 다른 기능을 쓰고 있다면: 앱 설정의 **앱 아이콘으로 열 때도 바로 녹음**을 켜면 아이콘을 누를 때 바로 듣기를 시작해요.
- 빠른 설정(화면 위에서 내리는 메뉴)에 **바로 기록** 타일을 추가해 써도 돼요.

## 4. 말을 못 알아들을 때
기기 안 음성 인식이 응답하지 않는 기기도 있어요. 그럴 땐 앱 설정의 **기본 음성 인식 함께 쓰기**를 **허용**하세요. (기본 음성 인식은 기기 설정에 따라 음성을 외부 서버로 보낼 수 있어요.) 허용하지 않아도 녹음 원본은 보관돼요.

## 업데이트와 개인정보
- 화면 업데이트는 앱을 열 때 자동으로 받아, 다음에 열 때 적용돼요.
- 휴대폰 기능이 바뀌는 드문 업데이트는 앱 설정 → **앱 업데이트**에 **업데이트** 버튼이 떠요. 누르고 설치 화면에서 **업데이트**를 누르면 돼요(처음 한 번은 "이 출처 허용"을 물어봐요). 기록은 그대로예요.
- 기록은 각자 기기 안에만 저장돼요. 이 저장소에는 앱 프로그램만 있고, 누구의 기록도 올라오지 않아요.
- 업데이트 파일은 서명되어 있어, 다른 사람이 만든 가짜 업데이트는 앱이 거부해요.
