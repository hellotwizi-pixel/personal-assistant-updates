# 내 비서 · 설치와 사용 안내

말 한마디로 일정·할 일을 남기는 개인 비서 앱이에요. **처음 한 번만 설치하면, 그 뒤 업데이트는 앱이 알아서 받아요.**
기록은 각자 휴대폰 안에만 저장돼요. 누구의 기록도 다른 사람이나 이 페이지로 올라오지 않아요.

- 필요한 것: **안드로이드 13 이상** 휴대폰 또는 태블릿, 인터넷 (아이폰은 지원하지 않아요)
- 걸리는 시간: 약 5분

---

## 1. 설치하기

1. 휴대폰에서 아래 링크를 누르세요.
   **[내 비서 0.4.5 설치 파일 받기](https://github.com/hellotwizi-pixel/personal-assistant-updates/releases/download/v0.4.5/personal-assistant-0.4.5.apk)**
2. 브라우저가 "이 파일을 다운로드할까요?"라고 물으면 **다운로드**를 누르세요.
   (크롬은 "유해할 수 있는 파일" 경고가 뜰 수 있어요 → **다운로드**)
3. 다운로드가 끝나면 알림이나 화면 아래의 **열기**를 누르세요.
4. **"출처를 알 수 없는 앱"** 안내가 뜨면 → **설정** → **이 출처 허용**(또는 "출처를 알 수 없는 앱 설치 허용")을 켜고 → 뒤로 돌아와 **설치**를 누르세요.
5. **Google Play 프로텍트** 경고("검사되지 않은 앱")가 뜨면 → **세부정보 더보기** → **그래도 설치**를 누르세요.
   스토어에 올리지 않은 개인 배포 앱이라 뜨는 경고예요.
6. **열기**를 누르면 설치 끝이에요. 홈 화면에 **내 비서** 아이콘이 생겨요.

## 2. 처음 열었을 때 꼭 켤 3가지

앱 오른쪽 위 **톱니바퀴(설정)** → **빠른 입력과 알림**에서 아래 세 줄의 **설정** 버튼을 하나씩 눌러 켜 주세요.

| 항목 | 왜 필요한가요 | 켜는 법 |
|---|---|---|
| **마이크 권한** | 말로 기록하려면 필요해요 | 설정 → **허용** (또는 "앱 사용 중에만 허용") |
| **알림 표시** | 약속 알림을 받으려면 필요해요 | 설정 → **알림 허용** 켜기 |
| **정확한 시각의 알림** | 약속 직전 알림이 정확한 시각에 울리려면 필요해요 | 설정 → **알람 및 리마인더 허용** 켜기 |

세 줄이 모두 "허용됨"으로 바뀌면 끝이에요.

**알림이 늦거나 안 오면 (삼성 기기):** 기기 설정 → 애플리케이션 → 내 비서 → **배터리** → **제한 없음**으로 바꿔 주세요.

## 3. 측면 버튼으로 바로 기록 (가장 편한 방법)

버튼 두 번으로, 앱 화면을 거치지 않고 곧바로 말을 받아 적어요.

1. 기기 **설정** → **유용한 기능** → **측면 버튼**
2. **두 번 누르기**를 켜고 → **앱 열기** → **내 비서**를 고르세요.
   목록에는 "내 비서"만 보여요. 그게 맞아요. 측면 버튼으로 열면 바로 듣기를 시작하고, 아이콘으로 열면 평소처럼 첫 화면이 열려요.
3. 이제 측면 버튼을 두 번 누르고 말하세요. 말이 끝나면 저절로 저장돼요.

- 잠금 화면에서는 잠금을 먼저 풀어야 할 수 있어요.
- 측면 버튼이 없거나 다른 기능에 쓰고 있다면: 앱 설정의 **앱 아이콘으로 열 때도 바로 녹음**을 켜면, 아이콘을 누를 때 바로 듣기를 시작해요.
- 화면 위에서 내리는 **빠른 설정**에 **바로 기록** 타일을 추가해 써도 돼요(빠른 설정 → 연필(편집) → "바로 기록"을 끌어다 놓기).

## 4. 이렇게 말해 보세요

화면 아래 가운데 **마이크** 버튼을 누르거나 측면 버튼을 두 번 누르고 말하면, 앱이 알아서 나눠 저장해요.

| 말하기 | 저장되는 모습 |
|---|---|
| "내일 오후 3시에 치과 예약" | 내일 오후 3시 약속 + 시작 전 알림 |
| "견적서 보내기 금요일까지" | 금요일 마감 할 일 (시각은 붙이지 않아요) |
| "매주 금요일 오전 10시 팀 회의" | 매주 반복 약속 |
| "견적서 보내기 다음주 월요일로 미뤄줘" | 그 할 일의 날짜만 바꿔요 |
| "읽고 싶은 책 데미안" | 날짜 없는 기록 |

- 애매한 내용(어느 폴더인지 모를 때 등)은 **확인함**(i 버튼)에 모아 두니, 시간 날 때 한꺼번에 정리하면 돼요.
- 가운데 **하루 브리핑** 구슬을 누르면 오늘 할 일과 오늘 일정을 비서처럼 읽어 줘요.
- **일정** 탭에서 월·2주·1주 달력으로 볼 수 있어요(1주·2주는 옆으로 밀어 보세요).
- **프로젝트** 탭의 **편집**에서 폴더 이름·아이콘을 바꾸고 추가·삭제할 수 있어요. 처음엔 개인일정·업무·취미 3개가 있어요.

**약속 알림 규칙:** 약속까지 60분 이상 남았으면 60분 전, 30~60분이면 30분 전, 10~30분이면 10분 전, 10분 안이면 등록 직후에 한 번 알려 줘요.

## 5. 말을 못 알아들을 때

기기 안 음성 인식이 응답하지 않는 기기가 있어요. 그럴 땐 앱 설정 → **기본 음성 인식 함께 쓰기** → **허용**을 눌러 주세요.
(기본 음성 인식은 기기 설정에 따라 음성을 외부 서버로 보낼 수 있어요.)
허용하지 않아도 녹음 원본은 **확인함**에 보관돼요. 거기서 **다시 받아쓰기**나 **직접 적기**를 할 수 있어요.

## 6. 업데이트

- **화면 업데이트:** 앱을 열 때 자동으로 받아 두었다가, 다음에 열 때 적용돼요. 할 일이 없어요.
- **앱 업데이트(드물게):** 앱 설정 맨 위 **앱 업데이트**에 **업데이트** 버튼이 떠요 → 누르고 → 설치 화면에서 **업데이트**. 기록은 그대로예요.
  - 처음 한 번 **"이 출처의 앱 설치 허용"** 화면이 떠요. 여기서 **허용**을 켜야 해요.
  - **"앱 업데이트를 마치지 못했습니다"**가 뜨면: 기기 설정 → 애플리케이션 → 내 비서 → **출처를 알 수 없는 앱 설치** → **허용**을 켜고, 업데이트를 다시 누르세요.
- 업데이트를 바로 확인하고 싶으면 앱 설정 → 앱 업데이트 → **지금 확인**.

## 7. 백업과 기기 바꾸기

기록은 휴대폰 안에만 있어서, **앱을 지우면 기록도 사라져요.**
- 앱 설정 → **개인정보와 백업** → **암호화 백업**으로 파일을 만들어 두세요(비밀번호를 정해요).
- 새 기기에서는 앱을 설치한 뒤 **백업 복원**으로 그 파일과 비밀번호를 넣으면 돼요.
- 기기 두 대를 자동으로 맞춰 주는 기능은 개인 서버(Mac)를 연결한 경우에만 돼요. 일반 사용은 한 기기를 권해요.

## 8. 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| 설치가 막혀요 | 1번의 4·5단계(출처 허용, 그래도 설치)를 확인하세요 |
| 측면 버튼으로 열면 첫 화면만 떠요 | 측면 버튼 설정에서 **앱 열기 → 내 비서**인지 확인하세요 |
| 알림이 안 와요 | 2번의 세 가지 허용 + 배터리 **제한 없음**을 확인하세요 |
| 말이 글로 안 바뀌어요 | 5번의 **기본 음성 인식 함께 쓰기**를 허용하세요 |
| 보고 탭이 비어 있어요 | 보고는 개인 서버(Mac)를 연결한 사람만 받아요. 일반 사용에서는 비어 있는 게 정상이에요 |
| 앱 업데이트가 실패해요 | 6번의 "출처를 알 수 없는 앱 설치 허용"을 켜세요 |

## 개인정보와 안전

- 기록은 기기 안에 암호화되어 저장돼요. 광고·분석 도구는 들어 있지 않아요.
- 이 페이지에는 앱 프로그램만 있어요. 누구의 기록도 올라오지 않아요.
- 업데이트 파일은 서명되어 있어서, 다른 사람이 만든 가짜 업데이트는 앱이 거부해요.
